About the Developer

Hi, I'm Aldi Nova. I created this phishing detection extension as both a portfolio project and a learning resource to explore how machine learning can be integrated into browser extensions. The Random Forest model was trained on phishing URL datasets and runs entirely client-side, meaning your browsing data never leaves your device.

This project represents my end-to-end learning journey—from dataset preparation, feature engineering, and model training in Python to deployment as a Chrome extension with real-time classification in JavaScript. It demonstrates the practical application of AI in solving real-world cybersecurity challenges while continuously improving my skills in machine learning, web development, and software engineering.
